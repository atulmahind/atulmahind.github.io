# Noto Sans Devanagari

Regular (400) and bold (700), served locally as WOFF2 with `font-display: swap`.
These fonts include Devanagari and Latin glyphs; they are not subset to current
page content, so future Marathi posts retain their character coverage.

Source: Google Fonts CSS API, Noto Sans Devanagari v33:
<https://fonts.googleapis.com/css2?family=Noto+Sans+Devanagari:wght@400;700&display=swap>

The static TTF files were converted to WOFF2 using fontTools 4.68.0 and
Brotli 1.2.1 without changing glyphs. The SIL Open Font License is included in
`OFL.txt`; its upstream source is:
<https://github.com/google/fonts/blob/main/ofl/notosansdevanagari/OFL.txt>.
